# PorterPacker_data
 A starting point for folks who want to use PorterPacker. Includes individual job files that include equippable Ambuscade weapons, all base artifact, relic, empyrean and reforged versions of armor.
 
## Repositories
 [gimlic1](https://github.com/gimlic1/Windower-addons/tree/0d9c4f24de098344ff05d4df79f1a9cfe18700b9/PorterPacker)
 [Ivaar](https://github.com/Ivaar/Windower-addons/tree/6596d4958b2d3a3f780c53c6480ccfc5bcf9ceca/PorterPacker)
 
 
## Usage 
 - Keep the slips you want in your inventory when you ```//po unpack``` or include something similar in your gearswap organizer file when you use ```//gs org```
